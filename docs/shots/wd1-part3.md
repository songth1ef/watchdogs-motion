## 已知差距

- 98.2 交接帧：s96 的车是 2D 剪影、这里是 3D 替身，形状略有差别；位置、大小、字标、平板四边、地平线一致。99–104 的相机绕转方向/距离与原片仍有偏差（原片更近、平板更大）。

- 100–111 物件是替身几何体，质感（半透明全息、线框 ATM 的细节）和原片差距最大；低机位段相机轨迹只大致对上。
- 素模城市全是方块，缺原片的异形楼和湖岸；俯拍段街道方向与原片有十几度偏差；129–133 原片右下有一片亮灰色地面（湖面/桌面），这里是黑的。
- 手机段的手机没有圆角与屏幕 UI；桌面地砖尺度、亮度是估的。
- 舞台是 2D 剪影，后拉没有视差；原片舞台灯的体积光、地面小屏的透视都做了简化。
- NETWORK 段 112–114 各色块的运动轨迹只卡了几个关键时刻，中间是插值，和原片的甩镜速度曲线不完全一样。

## 建议上提到共享库

- `part3/three-util.ts`：`orbitAt()/applyOrbit()`（关键帧轨道相机，含 `shift` 移轴 = `setViewOffset`）、`renderShadowed()`（临时打开共享 renderer 的 PCFSoft 阴影再恢复，避免影响别的镜头）、`project()`（世界坐标 → 1920×1080 画布坐标，用来把 2D 标签贴到 3D 物体上）。建议上提到 `src/three/` 或 `src/engine/three-host.ts`。
- `part3/layout.ts`：`blockLayout()`——「填满街区」的素模城市布局（街区切 1/2/4 块、屋顶小体块、可按位置控制高楼概率 `tallAt`、支持非正方形城市），比 `three/city.ts` 的 `cityLayout()` 更接近 WD1 素模城市，建议并入 `src/three/city.ts`。
- `part3/network.ts`：`keyed()`（多值关键帧插值，段内缓动）——几乎每个镜头都在手写这种插值，建议放进 `src/engine/math.ts`。
- `part3/util.ts`：`condensedText()`（窄体粗字，按目标宽度横向缩放）、`scrambleLR()`（从左往右解出的乱码，可指定字符集）、`F30()`（30fps 帧号）。可并入 `src/fx/text.ts`。
- `part3/logo.ts` 的故障标志做法（上半完整 / 下半切片 + 缺口嵌字符 / 像素溃散 `dissolve()`），可抽成 `fx/glitch.ts` 里的 `glitchLogo(src, state)`，WD2 片尾也用得上。
